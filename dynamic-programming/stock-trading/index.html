6四题差异与 Java 公式

题目买入时卖出时返回
121 一次max(旧持股, -price)max(旧不持股, 旧持股+price)不持股
122 无限次max(旧持股, 旧不持股-price)max(旧不持股, 旧持股+price)不持股
123 两次第一次从 0 买；第二次从第一次卖出买从对应的持股状态卖出第二次卖出
188 k 次第 m 次从第 m-1 次卖出买入第 m 次从第 m 次持股状态卖出第 k 次卖出

按本页下标约定：121/122 使用 [不持股, 持股]；123 使用 [第一次买入, 第一次卖出, 第二次买入, 第二次卖出]；188 使用 [第一次买入, 第一次卖出, 第二次买入, 第二次卖出, …]。未执行的交易允许作为零利润虚拟状态，因此结果表示「最多 k 次」而非「恰好 k 次」。
