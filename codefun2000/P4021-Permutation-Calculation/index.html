回溯为什么要“恢复现场”？
例如 path = [1, 2, 3] 已经输出了一个答案。回到上一层时先撤销 3，path 变成 [1, 2]；再撤销 2，path 变回 [1]，此时 2 可再次被其他分支选择，但当前层接下来应该尝试 3，从而进入 [1, 3]。回溯并不是删除答案，而是恢复搜索现场。
